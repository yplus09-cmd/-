MP3 음악 정리함 — Windows 10/11 64비트

ZIP 전체를 압축 해제한 뒤 MP3Organizer.exe를 실행하세요. runtime 폴더를 옆에 유지하세요. Python 별도 설치 없이 브라우저가 열립니다.

제목·음악가·장르·연도 일괄 수정, ID3v2.3 통일, 선택적 파일명 정리를 지원합니다. 원본 파일은 보존하고 수정된 복사본을 ZIP으로 다운로드합니다. 처리는 자신의 PC에서 수행됩니다. 실행 창을 닫으면 종료됩니다.

Windows 실행 파일 구조, ZIP 무결성과 Linux에서의 MP3 처리 기능을 검증했습니다. 실제 Windows 실행은 미검증이며 코드 서명되지 않았습니다.
